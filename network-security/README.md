# 🧱 Network Security Labs

## 🧭 Purpose

This section of my GitHub portfolio demonstrates **network-level security engineering** across multiple vendors and topologies.  
It complements the **Enterprise Cybersecurity Lab (ECL)**, which integrates these components into a larger multi-domain environment featuring **Active Directory**, **Splunk**, and **Security Monitoring**.

---

## 🧩 Lab Design Highlights

- **Multi-Vendor Topology:** Palo Alto + Fortinet edge and branch firewalls  
- **Layer 2 / Layer 3 Routing and NAT** between environments  
- **VPN Tunnels:** IPSec, Overlapping Subnets, and Backup Failover  
- **Identity & SSL Decryption:** AD-based User-ID and HTTPS inspection  
- **Centralized Management:** Panorama and FortiManager (future phase)
