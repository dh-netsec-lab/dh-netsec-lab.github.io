# 🌐 Routing & Switching Labs

Welcome to my **Routing & Switching Lab Series** — a collection of foundational and advanced network engineering labs demonstrating enterprise routing, switching, and WAN technologies.

Each lab is built in **EVE-NG** and focuses on real-world configurations that bridge traditional networking with modern security practices.
