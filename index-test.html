🏢 Enterprise Cybersecurity Lab (ECL) Overview

The Enterprise Cybersecurity Lab (ECL) is a fully integrated, multi-vendor environment designed to simulate real-world enterprise security architecture. It brings together Identity & Access (AD, PKI, ClearPass), Network Security (Palo Alto, Fortinet, VeloCloud), and a complete SOC detection pipeline (Suricata, Zeek, Wazuh, Sysmon, Splunk) into a single, cohesive cybersecurity ecosystem.
