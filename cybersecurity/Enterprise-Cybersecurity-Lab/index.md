# Enterprise Cybersecurity Lab (ECL)

Welcome to the ECL — a full SOC environment integrating:

- Suricata IDS
- Zeek NTA
- Wazuh SIEM
- Sysmon
- Splunk
- Windows AD
- Firewall telemetry and logging
- Multi-phase detection pipeline

## Available Phases
- **Phase 1:** Network Connectivity  
- **Phase 2:** Security Visibility & Telemetry  
- **Phase 3:** Identity & Trust  
- **Phase 4:** Threat Detection & SOC Pipeline  
- **Phase 5:** GRC & Reporting (Upcoming)
