# Identity & Trust Integration

Welcome to the **Identity & Trust** section of the Enterprise Cybersecurity Lab (ECL).  
This phase focuses on directory services, certificate trust, identity-based access, and foundational security controls used across enterprise environments.

---

## 🔐 What’s Included in This Phase

- **Active Directory Domain Services (AD DS)**
- **DNS & Name Resolution**
- **Certificate Authority (AD CS)**
- **Group Policy**
- **User & Computer Identity Management**
- **ClearPass Integration** (coming soon)
- **Identity-based access controls**

These components provide the identity layer that supports authentication, authorization, and trust relationships across the entire ECL environment.
