Enterprise Cybersecurity Lab (ECL)

Multi-site enterprise security environment focused on firewall enforcement, identity services, telemetry, and detection operations.

Executive Overview

The Enterprise Cybersecurity Lab (ECL) is a multi-site environment built to simulate real-world network and security operations. It brings together network segmentation, firewall enforcement, identity services, and centralized logging into one working system.

The lab spans multiple locations and includes connectivity to external environments like AWS and secure web gateways. This allows for realistic north/south and east/west traffic flows across a distributed enterprise setup.

Security Stack Overview

  • Network Security: Segmented zones (management, user, server, DMZ) with policy enforcement, NAT, and inspection through Palo Alto firewalls.
  • Detection & Response: Centralized logging pipeline using network and endpoint data for correlation and alerting.
  • Identity & Access: Active Directory and ClearPass providing authentication, authorization, and identity-based access control.
  • Application Security: Web applications and vulnerable systems used to test detection and response scenarios.
  • Monitoring & Operations: SOC and NOC visibility through logging, monitoring, and performance tools.
  • Hybrid Connectivity: Integration with AWS and external services to simulate real enterprise traffic flows.

Technologies used include Splunk, Sysmon, Suricata, Zeek, Wazuh, Nessus, Palo Alto Panorama, FortiManager, and other supporting tools.
