# Module 2 --- Basic Network Enumeration (ARP + ICMP)

## Objective

This module demonstrates how Suricata and Zeek detect **basic network
enumeration**: - ARP sweep traffic\
- ICMP echo probes\
- Validation that the IDS sees both east/west broadcast traffic and
directed probes.

------------------------------------------------------------------------

# 1. Generate ARP & ICMP Enumeration

From Kali attacker:

``` bash
nmap -sn 10.0.2.0/24
```

This produces: - ARP broadcast (who-has?)\
- ICMP echo probes to live hosts

------------------------------------------------------------------------

# 2. Validate IDS Visibility

## ✅ Step 1 --- Suricata ARP visibility (tcpdump)

``` bash
sudo tcpdump -ni ens4 arp
```

Expected screenshot: **suricata-tcpdump-arp-mmdd.png**

------------------------------------------------------------------------

## ✅ Step 2 --- Suricata ICMP visibility (tcpdump)

``` bash
sudo tcpdump -ni ens4 icmp
```

Expected screenshot: **suricata-tcpdump-icmp-mmdd.png**

------------------------------------------------------------------------

## ✅ Step 3 --- Suricata ARP/ICMP in eve.json

``` bash
sudo grep '"arp"' /var/log/suricata/eve.json
sudo grep '"proto":"ICMP"' /var/log/suricata/eve.json
```

Expected screenshot(s): - **suricata-eve-arp-mmdd.png** -
**suricata-eve-icmp-mmdd.png**

------------------------------------------------------------------------

## ✅ Step 4 --- Zeek conn.log Enumeration Events

``` bash
cat /opt/zeek/logs/current/conn.log | grep icmp
cat /opt/zeek/logs/current/conn.log | grep arp
```

Expected screenshot: **zeek-connlog-enum-mmdd.png**

------------------------------------------------------------------------

# 3. Analysis Notes

### ARP Observed:

-   Broadcast requests from 10.0.3.254 or 10.0.2.23\
-   Suricata accurately logs ARP discovery

### ICMP Observed:

-   ICMP host‑unreachable messages generated by the firewall (.254)
-   ICMP echo probes from attacker (10.0.2.23)

### Zeek Observations:

-   ICMP flows recorded in conn.log\
-   ARP module active (Zeek -N confirms ARP analyzer)
