# 🔎 Detection Engineering — SOC-102

Detection Engineering (SOC-102) builds on foundational SOC skills and progresses toward designing, validating, and tuning security detections using enterprise telemetry.

This section focuses on **how detection logic is created**, how signals are evaluated, and how visibility gaps are identified across network and host data.

---

## 🎯 What SOC-102 Covers
- Network behavior baselining
- East / West traffic visibility
- Reconnaissance and scanning detection
- Multi-host correlation
- Detection tuning and noise reduction
- Understanding visibility gaps

SOC-102 emphasizes **engineering reliable signals**, not reacting to alerts.
