Overview

This lab simulates a production-style hybrid datacenter architecture integrating on-prem infrastructure with AWS using Palo Alto firewalls, Transit Gateway, and BGP-based routing. The design includes a spine-leaf fabric, dual ISP edge, VRF segmentation, and full traffic inspection.

Key Components

  • Spine-Leaf Datacenter Fabric (Juniper)
  • Palo Alto Firewalls (Active/Passive HA)
  • VRF Segmentation (INET, DC, WAN)
  • Dual ISP Edge with BGP
  • AWS Transit Gateway Integration
  • IPSec VPN + BGP Routing

Traffic Flow

North-South traffic flows from the internet through edge routers into Palo Alto firewalls, then into the datacenter fabric. East-West traffic between internal segments is routed through the firewall to ensure visibility and policy enforcement.

Technologies Used

  • AWS Transit Gateway
  • BGP (eBGP & iBGP)
  • IPSec VPN
  • VRFs
  • Juniper JunOS (vQFX)
