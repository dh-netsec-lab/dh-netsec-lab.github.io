Overview

This lab simulates a production-style hybrid datacenter architecture integrating on-prem infrastructure with AWS using Palo Alto firewalls, Transit Gateway, and BGP-based routing. The design includes a spine-leaf fabric, dual ISP edge, VRF segmentation, and full traffic inspection.

Architecture Diagram

Key Components

  • Spine-leaf datacenter fabric built with Juniper vQFX
  • Palo Alto firewalls deployed in Active/Passive HA
  • VRF segmentation for INET, DC, and WAN routing domains
  • Dual-ISP edge with BGP routing
  • AWS Transit Gateway integration
  • IPSec VPN with dynamic route exchange through BGP

Traffic Flow

North-south traffic flows from the internet through the edge routers into the Palo Alto firewalls and then into the datacenter fabric. East-west traffic between internal datacenter segments is routed through the firewalls to provide visibility, segmentation, and policy enforcement.

Technologies Used

  • Palo Alto Networks (PAN-OS, Panorama)
  • AWS Transit Gateway
  • BGP (eBGP and iBGP)
  • IPSec VPN
  • VRFs
  • Juniper JunOS (vQFX)

Design Decisions

  • Implemented a spine-leaf architecture to model scalable east-west traffic patterns used in modern datacenters.
  • Deployed Palo Alto firewalls as a routed security boundary to enforce policy and provide full traffic inspection.
  • Centralized Layer 3 gateway functionality for datacenter VLANs on the Palo Alto firewalls so east-west traffic traverses security controls.
  • Used VRF segmentation to isolate routing domains and reflect enterprise network design practices.
  • Integrated AWS using Transit Gateway to model hybrid cloud connectivity with centralized routing control.
  • Leveraged BGP for dynamic route exchange across edge, datacenter, and cloud environments.

Palo Alto Role Relevance

  • Applied VRF-based segmentation for secure traffic isolation
