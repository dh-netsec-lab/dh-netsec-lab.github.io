## 🧭 Lab Purpose

The goal of this portfolio is to demonstrate how modern enterprises achieve **secure, observable, and resilient infrastructure** through:

- 🔐 Firewall and perimeter defense (Fortinet & Palo Alto)
- 🧠 Security monitoring and SIEM integration (Sysmon, Rsyslog, Splunk)
- ☁️ Cloud and DR readiness (AWS, site failover, VPN continuity)
- ⚙️ Configuration automation and infrastructure-as-code (PowerShell, Ansible)
- 🧩 GRC overlays for tracking risk, controls, and mitigations

This lab is designed to evolve — each phase introduces new integrations, visibility layers, and security maturity milestones.
